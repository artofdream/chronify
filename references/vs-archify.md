# Chronify vs Archify

| | Archify | Chronify |
|---|---|---|
| Question | What exists / how connected / what state? | What happened when? |
| Types | architecture, workflow, sequence, dataflow, lifecycle | timeline |
| Spine | topology or state rail | **date** axis |
| Jumps | optional views | `#slug` / href to narrative sections |

Use both: Archify for Decision Layer map; Chronify for journal evolution rail.
